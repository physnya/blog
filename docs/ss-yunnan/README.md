参加 ICESUN 的暑期学校，大约一周，今年在中科院云南天文台 (地处昆明) 举办.

为什么叫 ICESUN？官方解释是：InternationalCEntre of SUperNovae $=$ ICESUN. 还挺有意思.

2026 这一期暑期学校的主题是 Stellar Evolution, Supernova Explosion, and Nucleosynthesis. 具体信息可以看 [官方网页](https://icesun-summer-school2026.casconf.cn/).
