广义相对论的可观测效应

我们的核心讨论是，什么时候必须用广义相对论.

狭义相对论效应回顾

  • 光速不变原理. 这引入了 Lorentz 因子，

    γ=11−v2/c2\gamma = \frac{1}{\sqrt{1-v^2/c^2}} γ=1−v2/c2​1​

  • 时间延缓效应：Δt=γΔτ\Delta t=\gamma\Delta\tauΔt=γΔτ.

  • 长度收缩效应：L=L0/γL=L_0/\gammaL=L0​/γ.

  • 能量与动量的变换：E=γmc2E=\gamma mc^2E=γmc2，p=γmvp=\gamma mvp=γmv.

  • 相对论集束：或者说前灯效应，在速度方向的发射粒子分布更多.

广义相对论简介

『等效原理』引力加速度 (引力质量) 和惯性加速度 (惯性质量) 无法被区分.

我们先从真空静态球对称解开始，Einstein 方程给出

Gμν+Λgμν=8πGc4TμνG_{\mu\nu}+\Lambda g_{\mu\nu} = \frac{8\pi G}{c^4}T_{\mu\nu} Gμν​+Λgμν​=c48πG​Tμν​

对于真空静态情况，能动张量 Tμν=0T_{\mu\nu}=0Tμν​=0，且 Λ=0\Lambda=0Λ=0 (不考虑暗能量的驱动)，则

Gμν≡Rμν−12Rgμν=0,R=RμνgμνG_{\mu\nu} \equiv R_{\mu\nu}-\frac{1}{2}Rg_{\mu\nu}=0,\quad R = R_{\mu\nu}g^{\mu\nu} Gμν​≡Rμν​−21​Rgμν​=0,R=Rμν​gμν

在球坐标下，解得静态球对称真空解 (Schwartzchild 度规)：

ds2=−(1−2GMrc2)c2dt2+(1−2GMrc2)−1dr2+r2(dθ2+sin⁡2θdϕ2)\mathrm{d}s^2=-\left(1-\frac{2GM}{rc^2}\right)c^2\mathrm{d}t^2+\left(1-\frac{2GM}{rc^2}\right)^{-1}\mathrm{d}r^2+r^2(\mathrm{d}\theta^2+\sin^2\theta\mathrm{d}\phi^2) ds2=−(1−rc22GM​)c2dt2+(1−rc22GM​)−1dr2+r2(dθ2+sin2θdϕ2)

几个更加好记忆的结论是某些「等效」的量：定义视界半径为 rS=2GM/c2r_S=2GM/c^2rS​=2GM/c2.

  • 等效光速：c′=drdt=(1−rSr)cc'=\displaystyle{\frac{\mathrm{d}r}{\mathrm{d}t}=\left(1-\frac{r_S}{r}\right)c}c′=dtdr​=(1−rrS​​)c，这个量和位置关联，因此产生光线偏折效应.

  • 等效 Lorentz factor：

    γg=11−v2/c2=11−rS/r\gamma_g = \frac{1}{\sqrt{1-v^2/c^2}} = \frac{1}{\sqrt{1-r_S/r}} γg​=1−v2/c2​1​=1−rS​/r​1​

    因此有所谓的引力红移.

这里的两个可观测效应就是引力场造成的时间延缓和引力红移.

光线偏折和引力透镜：偏折角为

4GMc2b\frac{4GM}{c^2b} c2b4GM​

(bbb 为瞄准距离.) 这个结果是 Newton 光学给出的结果的两倍.

Schwartzchild 进动：定义伪引力势 (Paczynski-Wilta 势)

Φgr=−GMr−rS\Phi_{gr}=-\frac{GM}{r-r_S} Φgr​=−r−rS​GM​

则单位周期内，轨道近日点将偏离

Δϕ=3πrSa(1−e2)\Delta\phi=\frac{3\pi r_S}{a(1-e^2)} Δϕ=a(1−e2)3πrS​​

另外的效应：引力波辐射/ISCO 和光子球/Shapiro 时延

  • ISCO 和光子球：ISCO 指有质量粒子的最内侧稳定圆轨道，可以用上述伪引力势导出，对于 Schwartzchild 黑洞，其值为 3rS3r_S3rS​；而光子球是无质量粒子的最内侧稳定圆轨道，对于 Schawartzchild 黑洞，其值为 1.5rS1.5r_S1.5rS​.

  • Shapiro 时延：光线传播经过引力场会发生时间延迟，因为光线偏折导致了路程变化. 但是这件事情基本只能在双星系统中观察到 (太阳的延时很弱)，在双星互相经过时，产生一个

    Δt=rScln⁡{1−Scos⁡[2π(ϕ−ϕ1)]}\Delta t = \frac{r_S}{c}\ln\left\{1-S\cos[2\pi(\phi-\phi_1)] \right\} Δt=crS​​ln{1−Scos[2π(ϕ−ϕ1​)]}

    时延的变化幅度 rrr 由伴星质量决定，

    r=rSc=2GM2c3r = \frac{r_S}{c}=\frac{2GM_2}{c^3} r=crS​​=c32GM2​​

    时延的变化形状 (shape parameter SSS) 则由双星轨道倾角决定，
